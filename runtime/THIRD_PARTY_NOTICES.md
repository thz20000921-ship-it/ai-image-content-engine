# 第三方组件声明

本程序随包附带以下开源组件，各自遵循其原始许可。程序自身代码为本公司自有项目。

## CPython（内嵌 Python 运行时）

内嵌运行时由 Python Software Foundation 分发，许可见运行时目录内的许可文档：
https://docs.python.org/3/license.html

## Python 依赖包

WebUI 所需的 Python 包列在 `python-requirements.lock.txt`。各包遵循其自身许可
（常见为 MIT / BSD / Apache-2.0 / LGPL）。再分发修改过的包前请自行核对其许可。

## 前端依赖

WebUI 前端包含 Konva（MIT 许可）等 npm 包，来源与版本见前端打包脚本与锁文件。
